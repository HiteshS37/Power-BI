# Power BI Dashboard Portfolio

Collection of educational Power BI reports. **PBIX files require Power BI Desktop**; this repository has no live hosted dashboards.

| Report | Intended analysis |
|---|---|
| [Netflix_Data.pbix](Netflix_Data.pbix) | Catalogue patterns, types, genres, geography |
| [Super_Stores_Sales.pbix](Super_Stores_Sales.pbix) | Retail sales, categories and profitability |
| [Fact_Sales_Data.pbix](Fact_Sales_Data.pbix) | Sales-data exploration and KPI design |
| [Global Markets.pbix](Global%20Markets.pbix) | Global market analysis |

The topics are descriptive guides, **not verified findings**. Source datasets, DAX measures, model diagrams, report screenshots and conclusions have not yet been documented. Download a PBIX file and open it in Power BI Desktop; reconnect local data sources as needed.
